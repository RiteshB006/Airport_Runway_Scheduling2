Airport Runway Scheduling

Design and Analysis of Algorithms – Greedy Algorithm

Problem Statement

Airports have limited runways and multiple flights request landing or takeoff during specific time intervals. If two flights overlap on the same runway, it leads to delays and safety issues. The objective is to schedule the maximum number of non-overlapping flights.

Need for Algorithmic Solution

  • Manual scheduling causes conflicts
  • Checking all combinations is inefficient
  • Algorithm ensures optimal and fast scheduling

Users / Stakeholders

  • Air Traffic Controllers (ATC): Manage runway assignments safely
  • Airport Operations Team: Coordinates arrivals and departures
  • Airlines / Pilots: Need predictable schedules for flights
  • Passengers: Benefit from reduced delays
  • Airport Management: Monitors runway utilization and efficiency
  • Regulatory Authorities: Ensure compliance with aviation safety regulations

Solution Approach

We use the Greedy Algorithm (Activity Selection / Interval Scheduling) which selects flights based on earliest finishing time to maximize runway utilization.

Detailed Algorithm Explanation

The Greedy algorithm works as follows:

  1. Sorting: First, all flights are sorted according to their ending times in ascending order. This ensures that flights finishing earlier are considered first, leaving maximum time for subsequent flights.
  2. Selection: The flight with the earliest finishing time is always selected as the first flight. This is the “greedy choice” which ensures optimal usage of the runway.
  3. Checking overlap: For each subsequent flight, the algorithm checks if its starting time is greater than or equal to the ending time of the last selected flight. If yes, the flight is selected; otherwise, it is skipped.
  4. Repeat: This process continues until all flights have been considered.
  5. Result: The selected set of flights will always contain the maximum possible number of non-overlapping flights.

This algorithm guarantees an optimal solution because selecting the earliest finishing flight maximizes the remaining time for scheduling other flights, which is the key property of Greedy algorithms.

Why Greedy Algorithm?

  • Always selects the next flight that finishes earliest and doesn’t overlap with previous flights
  • Guaranteed to schedule the maximum number of non-overlapping flights
  • Time complexity: O(n log n) (sorting flights + selection)
  • Efficient for real-world airport operations requiring quick scheduling

Algorithm: Airport Runway Scheduling (Greedy Interval Scheduling)

  1. Sort all flights in non-decreasing order of their ending times
  2. Select the first flight (the one with the earliest finishing time)
  3. Let lastEnd = ending time of the selected flight
  4. For each remaining flight (in sorted order):
    • If start[i] ≥ lastEnd:
      • Select the flight
      • Update lastEnd = end[i]
  5. Stop when all flights are processed
  6. Output the selected flights

Pseudocode

ActivitySelection(start[], end[], n)
{
    sort activities by end time

    select first activity
    lastEnd = end[0]

    for i = 1 to n-1
        if start[i] >= lastEnd
            select activity i
            lastEnd = end[i]
}

C++ Implementation (Greedy Algorithm)

#include <iostream>
#include <algorithm>
using namespace std;

struct Flight {
    string id;
    int start;
    int end;
};

bool compareFlights(Flight a, Flight b) {
    return a.end < b.end;
}

void runwayScheduling(Flight flights[], int n) {
    sort(flights, flights + n, compareFlights);

    int lastEnd = -1;
    int count = 0;

    cout << "Scheduled Flights:\n";

    for (int i = 0; i < n; i++) {
        if (flights[i].start >= lastEnd) {
            cout << flights[i].id << " (" 
                 << flights[i].start << " - " 
                 << flights[i].end << ")\n";
            lastEnd = flights[i].end;
            count++;
        }
    }

    cout << "Total flights scheduled: " << count;
}

int main() {
    int n;
    cin >> n;

    Flight flights[n];

    for (int i = 0; i < n; i++) {
        cin >> flights[i].id
            >> flights[i].start
            >> flights[i].end;
    }

    runwayScheduling(flights, n);
    return 0;
}
